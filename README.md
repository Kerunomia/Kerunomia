# keru

i build low-level linux graphics stuff, mostly wayland compositors and the pieces around them. it's a clean loop: the code either runs or it doesn't, and it never asks how i'm doing.

right now that's **[vwl](https://github.com/Kerunomia/vwl)** — a tiling wayland compositor built on wlroots. infinite canvas, animations, a lua config so i don't have to recompile just to change my mind.

i like software small enough to hold in my head. so the projects stay small and the nights get long.

`C` · `Lua` · `Wayland` · `wlroots` · `Xwayland` · `Linux`
