# Keru

I write low-level Linux graphics software — mostly Wayland compositors, window
management, and the glue around them.

## Currently

**vwl** — a tiling Wayland compositor built on [wlroots](https://gitlab.freedesktop.org/wlroots/wlroots):
infinite canvas, animated layouts, layer-shell, Xwayland, and a runtime Lua config
so it never needs recompiling to change settings.

## Focus

- Wayland compositors and protocols
- Tiling / dynamic window management
- X11 and Xwayland integration
- Runtime-configurable systems (Lua over compiled-in config)

## Stack

`C` · `wlroots` · `Wayland protocols` · `X11 / Xwayland` · `Lua` · `Make` · `Linux`
