# keru

i'm russian. i live in a small city in siberia — Kyzyl, in Tuva — mostly because it's far from everything, and far is a kind of quiet.

i write low-level linux graphics code, mostly wayland compositors. it's a simple relationship: the program compiles or it doesn't, and either way it never asks how i'm doing. that's most of what i'm looking for.

right now that's **[vwl](https://github.com/Kerunomia/vwl)** — a tiling wayland compositor built on wlroots. infinite canvas, animations, a lua config so i don't have to recompile just to change my mind. it works, which is more than i can say for most things.

i like software small enough to hold in my head. so the projects stay small and the nights stay long. the sun goes down early here and i wasn't using it anyway.

`C` · `Lua` · `Wayland` · `wlroots` · `Xwayland` · `Linux`
