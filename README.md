I build low-level Linux graphics software — mostly Wayland compositors, window
management, and the strange little pieces around them. It's a good loop: the code
either runs or it doesn't, and it never asks me how I'm doing.

Right now I'm building **[vwl](https://github.com/Kerunomia/vwl)** — a tiling
Wayland compositor on wlroots. Infinite canvas, animated layouts, layer-shell,
Xwayland, and a Lua config so I can change my mind without recompiling my
mistakes.

I like things you can hold entirely in your head. That's getting harder, so I
keep the projects small and the nights long.
